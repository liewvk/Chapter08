## Build & Run

Use your preferred Java build tool (Maven, Gradle) or the JDK directly.

Example using javac/java:

```sh
# compile
javac -d out $(find . -name "*.java")

# run (replace com.example.Main with the actual main class)
java -cp out com.example.Main
```

If this project uses Maven or Gradle, run:

- Maven: `mvn package` then `java -jar target/<artifact>.jar`
- Gradle: `gradle build` then run the produced jar in `build/libs/`
